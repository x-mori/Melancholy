# Features

Melancholy brings member activities and server tools into one Discord bot. Feature availability follows each server's configuration and the permissions of the person using it.

## For members

### Profiles and progress

Profiles bring together activity, badges, charms, and personal details. Level cards show message progress, with an extended view of nearby ranked members. Stats cover activity such as messages and voice time. Members can browse leaderboards and choose whether to show their charm collection.

Starlight adds seasonal divisions and quests. Daily, weekly, and seasonal quest pages have separate views. It is a progression score, not a currency for purchases.

### Economy

Members can claim daily rewards, complete work activities, inspect balances and cooldowns, transfer currency, and use the shop. Server coins stay with the server; gems are tied to the account. Built-in work can award gems once per activity cooldown across servers. Server staff can add custom occupations and configure recurring income for selected roles.

### Things to do

Melancholy includes social actions, reputation, casual games, trivia, and a minigame with characters, equipment, training, hunting, inventory, a shop, and gacha. Anime search covers series, characters, studios, and people, with richer details where the connected services provide them.

### Everyday utilities

`/home` gathers common personal actions and reward readiness in one panel. `/help find` accepts a command name or a short goal such as `earn money`. Members can set AFK status, create reminders, view weather, browse image and color tools, and use context menu actions on messages or users.

## For server staff

- Moderation commands cover warnings, bans, kicks, mutes, and bulk message management.
- Configurable logs record server and moderation events.
- Settings and protection tools support moderation rules, automation, welcome and verification flows, and other server behavior.
- Role and economy tools include custom occupations and scheduled income for selected roles.
- Configuration snapshots let authorized staff save, compare, and restore supported settings.
- Activity and command analytics help staff see how the server uses Melancholy.

## Personal data controls

`/data privacy` summarizes personal server data. `/data export` downloads a JSON copy. `/data delete` requests removal of eligible personal server data and requires an explicit confirmation value. These actions are available through the bot; this public repository stores no user data.

For a command starting point, see [the command guide](COMMANDS.md). The live `/help` menu reflects the commands and permissions available in your server.
