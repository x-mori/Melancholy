# Maintaining this public repository

This repository is Melancholy's public project display. The private bot application lives in a separate repository. Keep this repository limited to documentation and approved media.

## Review before each update

1. Check the staged file list. It should contain only reviewed documentation and assets.
2. Update the version and release summary when the private application changes.
3. Check the [website](https://melancholy.fujiverse.dev/) and support links.
4. Inspect screenshots for tokens, user data, private channels, and server details before adding them.
5. Keep the `.gitignore` allowlist current when adding a new public file.

The initial published set is `README.md`, `FEATURES.md`, `COMMANDS.md`, `CHANGELOG.md`, `SUPPORT.md`, `NOTICE.md`, `PUBLISHING.md`, `.gitignore`, and `assets/melancholy-banner.svg`. Do not copy source, compiled output, credentials, or deployment configuration from the private checkout.
