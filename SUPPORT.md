# Support and feedback

For bot help, feature questions, or bug reports, visit the [Elegy support server](https://discord.gg/elegy). Include the command you used, what you expected, what happened, and whether the issue occurs in one server or several. Remove tokens, private messages, and personal data before sharing screenshots or logs.

The [Melancholy website](https://melancholy.fujiverse.dev/) is the public web home. Inside Discord, `/help` shows the commands available to your server and `/help find` can locate a command by task.

This repository is a project display. It does not accept application source patches because the application source is private.
